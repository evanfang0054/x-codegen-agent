# Claude 进度日志

本文件用于追踪长时间运行 Agent 会话的进度。每次会话结束后应在此追加更新记录。

## 使用说明

1. 每次会话开始时，阅读本文件了解之前完成的工作
2. 每次会话结束时，追加你的进度摘要
3. 保持记录简洁但信息丰富

## 记录格式

```
## [YYYY-MM-DD HH:MM] 会话摘要
- 完成了什么
- 正在进行什么
- 下一步需要做什么
- 任何阻塞或问题
```
