# 阶段 api-design：接口与数据逻辑设计

## 目标
基于研究结论完成接口 Schema 获取与数据流设计。

## 输入
- `research` 阶段产物
- API 规范与项目约定

## 执行动作
1. 获取接口定义（优先 MCP，失败回退本地文档/类型）
2. 明确请求参数、响应结构、异常分支
3. 设计页面数据流（初始化加载、提交、错误处理、状态管理）
4. 约束实现方式与类型边界

## 输出
- 接口与数据流方案
- 可落地的数据层实现计划

## 完成标准
- 核心接口可用且字段定义明确
- 数据流闭环完整（加载/提交/异常）
- 能直接支撑 `integration`

## 失败处理
- 接口不确定或数据流不闭环：停留本阶段补齐
- 禁止凭空假设关键参数后推进
