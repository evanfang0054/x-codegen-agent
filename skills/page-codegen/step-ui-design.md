# 阶段 ui-design：UI 组件与交互设计

## 目标
完成组件能力确认与关键交互设计，保持模板结构稳定。

## 输入
- `research` 阶段的功能清单
- `api-design` 阶段的数据约束

## 执行动作
1. 确认组件 API（优先知识库/组件文档，失败再回退本地定义）
2. 设计交互逻辑：联动、校验、按钮状态、路由跳转
3. 约束实现边界：保留既有 DOM 结构和样式语义，避免无关改造

## 输出
- 组件与交互设计结论
- 可执行的 UI 逻辑方案

## 完成标准
- 关键组件属性与行为明确
- 交互链路完整且可实现
- 可直接进入 `integration`

## 失败处理
- 组件能力不确定或交互冲突：在本阶段修正
- 禁止跳过组件能力确认直接编码
